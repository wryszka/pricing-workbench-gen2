Honest note for a customer room: today the buying-journey tools run as a custom MCP on Databricks Apps delegating to these UC objects; the reads/functions/Genie are the managed-MCP-native part. This diagram is the target-state reference shape — the App becomes a thin host as those tools graduate to managed MCP.

The agent gets a real carrier price from the live engine, plus a governed "why" — and Unity Catalog has a record of every call.
